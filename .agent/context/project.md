# Project Context

## Summary

`galperin` is an AI powered supplier scraper.

**Objective**: The objective is to allow users to search for products supplier across different suppliers site as alibaba. Users should be able to create a search task which shall create a new scrapper, and should be able to see the scrapped products after some time in a UI. The engine should store such processed results in a SQL like database

The repository is currently at bootstrap stage. Source code, runtime architecture, dependency management, and deployment conventions have not been established yet.
