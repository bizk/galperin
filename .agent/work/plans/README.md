# Plans

Plan files describe how a task will be implemented.

Plans should stay linked to task briefs and should be updated when implementation changes direction.

## Required Links

Each plan should link to:

- Matching task in `.agent/work/tasks/`
- Matching handoff in `.agent/work/handoffs/`, if one exists
- Relevant shared context in `.agent/context/`

## Template

Copy `_template.md` when creating a plan.
