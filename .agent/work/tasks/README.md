# Tasks

Task files define what needs to be done and why.

Create one task file per feature, bug fix, refactor, or research item. Keep implementation details in the matching plan unless they are part of the requirement.

## Required Links

Each task should link to:

- Matching plan in `.agent/work/plans/`
- Matching handoff in `.agent/work/handoffs/`, if one exists
- Relevant shared context in `.agent/context/`

## Template

Copy `_template.md` when creating a task.
